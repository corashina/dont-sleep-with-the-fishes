# Scavenging music concepts

Each concept lasts 60 seconds. Each uses a clear clock pulse and a rising final section.

## Selected runtime sequence

Use [The Chase](https://freesound.org/people/Victor_Natas/sounds/634513/) for the first 50 seconds.

Use [Time Running Out](https://freesound.org/people/qubodup/sounds/211102/) for the final 10 seconds.

Both sources require attribution.

## 1. Brass Stopwatch

Use a 128 BPM D-minor ostinato. Add muted reeds, dry plucks, low strings, and clock clicks.

The comic reed tone fits Dorothy. The minor harmony keeps the sinking ship melancholy.

This concept is not active.

## 2. Deckhand's Deadline

Use clipped concertina chords against a fast rope-drum pattern. Raise the bass line every eight bars.

This option feels more nautical and playful. It has less dread than Brass Stopwatch.

## 3. Sixty Seconds Below

Use pizzicato cello, muted piano, and one metal tap per beat. Shorten phrases near the end.

This option feels tense and restrained. It gives the ship sounds more space.

## 4. The Captain Miscounted

Use a crooked waltz at 168 BPM. Drop one beat from every fourth phrase.

This option feels darkly comic. Its uneven meter can make movement harder to read.

## 5. Rusted Escapement

Use struck metal, wood blocks, and a two-note harmonium warning. Add ticks in the last 15 seconds.

This option feels mechanical and grim. It best supports a stronger horror tone.
